[Render pricing](https://render.com/pricing): web 512 МБ $7, worker 2 ГБ $25, PostgreSQL 256 МБ $6. Для диска БД заложен консервативный запас $0.30/ГБ; точную включённую ёмкость нужно проверить при заказе. [Модель стоимости](https://render.com/articles/how-much-does-cloud-application-hosting-cost-for-small-businesses).

[One-off jobs](https://render.com/docs/one-off-jobs) оплачиваются посекундно, используют образ и окружение базового сервиса, но не его persistent disk. При эквиваленте $25/месяц и условных 720 часах: 10 часов обработки ≈ $0.35, 30 часов ≈ $1.04. Это расчёт, не измеренное время проекта. В оплачиваемое время входит ожидание API, загрузки, запуск и экспорт. В коде есть `worker-session.js`, но автоматический запуск таких заданий из UI пока не реализован. Поэтому это подготовленный ручной режим, а не уже развёрнутая полностью автоматическая облачная система.

Для файлов подходит [Cloudflare R2 Standard](https://developers.cloudflare.com/r2/pricing/): первые 10 ГБ-месяц, 1 млн операций A и 10 млн B бесплатно; далее хранение $0.015/ГБ-месяц. Например, 50 ГБ в среднем ≈ $0.60 за хранение сверх бесплатного объёма. Исходящий трафик R2 бесплатный, операции сверх квоты оплачиваются отдельно. S3-совместимый адаптер уже есть; аккаунт и bucket не создавались.

Оплата Render workspace не является общим пулом CPU для произвольных приложений: обнаружен один сервис `dukhy-lisu`, привязанный к другому репозиторию. Совместное размещение потребует изменения его запуска и увеличит связанность двух приложений. Инвентаризация не подтверждает свободную ёмкость или наличие денежных кредитов на аккаунте.

[Ограничения бесплатного Render](https://render.com/docs/free): бесплатная БД действует 30 дней; бесплатный web имеет ограничения и не сохраняет локальный диск. Не использовать для единственной копии рабочих проектов.

Рекомендация: сейчас локальный MVP ($0 новых фиксированных платежей). После проверки реальной генерации — отдельный web + PostgreSQL + R2 и явные сеансы обработки. Автоматическое создание облачных заданий следует добавлять отдельно с ограничением параллелизма, защитой от двойного запуска, таймаутом и подтверждённым бюджетом.
